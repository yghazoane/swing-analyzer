# 📈 محلل السوينق والأهداف الزمنية (Swing Analyzer)

أداة تفاعلية مبنية بلغة **Python** و إطار عمل **Streamlit** لتحليل مؤشرات السوق الكبرى (`SPY`, `QQQ`, `IWM`) والأسهم القيادية، وتحديد نقاط الدخول والأهداف السعرية والزمنية لعقود السوينق.

🔗 **رابط التطبيق المباشر:** [https://swing-analyzer.streamlit.app/](https://swing-analyzer.streamlit.app/)

---

## 🧠 منهجية التحليل والركائز الفنية للأداة

1. **جلب البيانات والتحقّق الفوري (Live Data & Fetching):**
   - جلب بيانات الأسعار التاريخية والحية عبر `yfinance` مع دعم الإطار اليومي (`1d`) والساعي (`1h`).
2. **المتوسطات المتحركة وفلتر الاتجاه (EMA Filters):**
   - حساب `EMA 20` و `EMA 50` لتحديد الاتجاه العام للسوق (*Trend Filter*).
3. **اكتشاف القمم والقيعان المحورية آلياً (Swing Pivots & Wave Structure):**
   - استخدام خوارزميات `SciPy` (`argrelextrema`) لرصد القمم والقيعان المحورية وتحديد هيكل الموجة الحالية.
4. **حساب الأهداف السعرية ونسب امتداد فيبوناتشي (Fibonacci Extensions):**
   - استخراج الهدف الأول عند امتداد **1.272** والهدف الثاني (الموجة الثالثة) عند امتداد **1.618**.
5. **تقدير الوقت المتوقع والزمن (Time Projections & DTE):**
   - قياس سرعة الموجة السابقة بالشموع وإسقاطها زمنياً لتقدير مدة الوصول للهدف، مع إضافة **21 يوماً كهامش أمان** لاختيار تاريخ انتهاء عقد الأوبشن (`DTE`) وتجنب تآكل الوقت (`Theta`).
6. **إدارة المخاطر وحساب متوسط المدى الحقيقي (ATR & Position Sizing):**
   - تحديد وقف خسارة ديناميكي باستخدام مؤشر `ATR` وحساب حجم الصفقة ونسبة العائد للمخاطرة (`R:R`).
7. **عزم الزخم (RSI Momentum):**
   - دمج مؤشر القوة النسبية `RSI (14)` لقياس تشبع السعر وقوة الزخم.
8. **العرض البصري التفاعلي (Plotly & Dashboard Visualization):**
   - شارت شموع يابانية تفاعلي (Dark Theme) مع إمكانية تعديل الحساسية والمخاطرة لحظياً من القائمة الجانبية.
